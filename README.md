Expense Tracker Using Python

1. Objective

To develop a Python-based Expense Tracker that allows users to record expenses, view all expenses, and calculate total and category-wise spending.

2. Technologies Used

- Python
- "csv" module
- "os" module
- "datetime" module
- Visual Studio Code

3. Features

- Add expenses with date, category, description, and amount.
- Automatically use today's date if no date is entered.
- Validate date format and expense amount.
- View all recorded expenses.
- Calculate total spending and category-wise expenses.
- Store expense records in a CSV file ("expenses.csv").

4. How to Run

1. Save the Python code as "expense_tracker.py".

2. Open the terminal in the project folder.

3. Run the program using:
   
   "python expense_tracker.py"

4. Select an option from the menu:
   
   - "1" – Add Expense
   - "2" – View Expenses
   - "3" – Spending Summary
   - "4" – Exit
